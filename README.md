# Coupon Service

## Running the application

### Requirements
- JDK
- Apache Maven
- Internet connection

Application is powered by Springboot with embedded Tomcat and HSQL in-memory database. Application can be run by executing following line:

`mvn spring-boot:run`. Once ready there should be a message:

`Tomcat started on port(s): 8080 (http)`

### Testing application
Once started, [open Swagger](http://localhost:8080/swagger-ui/index.html) in your browser and test APIs with "Try it out" or other preferred way.
